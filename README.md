# OurApp

Instagram-first personal memory layer.

## V1

Save Instagram Reels → understand them → store useful memory → search and revisit.

## Repository

- `docs/` — canonical engineering/product documentation
- `frontend/` — React + TypeScript + Vite application
- `backend/` — Python + FastAPI application
- `supabase/migrations/` — database migrations
