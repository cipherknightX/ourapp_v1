# Phase 1 — Foundation Start

Phase 0 is complete.

## First objective

Initialize the development toolchain and verify the repository foundation.

## Suggested order

1. Initialize Git if not already initialized.
2. Initialize React + TypeScript + Vite + Tailwind in `frontend/`.
3. Initialize FastAPI/Python tooling in `backend/`.
4. Establish formatting/lint/type/test commands.
5. Establish Docker/local development commands.
6. Establish Supabase project connection and first migration.
7. Implement authentication foundation.
8. Implement the basic application shell.
9. Only then begin Instagram integration.

## Agent rule

Do not implement Instagram functionality as part of repository initialization.

Read `docs/guardrail.md` and `docs/instructions.md` before making changes.
